## Dùng để làm gì

Soát cấu trúc và dữ liệu trong file Excel trước khi bạn nhập thay đổi vào WFX.

## Các bước

1. Mở module Catalog.
2. Chuyển sang khu Costing.
3. Bấm `Kiểm tra file`.
4. Chọn file Excel cần soát.
5. Đọc kết quả kiểm tra trên bảng điều khiển.
6. Mở đúng sheet và ô được báo để sửa lỗi.

## Mẹo

> [!meo]
> Nút `Kiểm tra file` chỉ đọc file Excel. Nút này không mở Costing và không
> thay đổi dữ liệu trên WFX.

## Gặp lỗi thì sao

| Hiện tượng | Cách xử lý |
|---|---|
| Báo thiếu sheet Costing | Dùng file được tải từ nút `Tải XLSX`, không đổi tên hoặc xóa sheet. |
| Báo lỗi ở một ô | Mở đúng địa chỉ ô được báo, sửa giá trị rồi kiểm tra file lại. |
| Không chọn được file | Kiểm tra file có đuôi .xlsx và không bị hỏng. |
