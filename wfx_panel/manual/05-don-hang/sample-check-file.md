## Dùng để làm gì

Tìm một Sample Order và xem các file đính kèm có thể tải về.

## Các bước

1. Mở module Sample List.
2. Nhập một hoặc nhiều điều kiện: Sample Order No., Style, Created By và Buyer.
3. Bấm `Xem file đính kèm`.
4. Chờ ứng dụng tìm Sample trước.
5. Chọn một dòng nếu có nhiều kết quả.
6. Bấm file cần tải trong danh sách kết quả.
7. Muốn xem file của Sample khác trong cùng lượt tìm, bấm `← Chọn Sample khác`
   rồi chọn dòng tiếp theo.

## Mẹo

> [!meo]
> Nếu chỉ có một kết quả, ứng dụng tự mở Style và liệt kê file. Nếu có nhiều
> kết quả, bạn chọn đúng Sample rồi ứng dụng tiếp tục ngay từ danh sách đang mở.

> [!meo]
> File nằm ở Style chứ không ở từng Sample. Khi mọi kết quả cùng một Style
> Code, ứng dụng mở luôn Style đó thay vì bắt bạn chọn.

> [!meo]
> Sample Order No. bắt đầu bằng `PSG-`, `PSW-` hoặc `PSK-` thuộc Division
> PSSG, Woven hoặc Knit. Ứng dụng tự chuyển sang đúng Division trước khi tìm và
> báo ở thanh trạng thái khi đã chuyển.

> [!meo]
> Sample đã xem file có dấu ✓ trong danh sách chọn. Danh sách chỉ hiện 20 dòng
> đầu; nếu có nhiều hơn, hãy thêm điều kiện để thu hẹp.

> [!meo]
> Ứng dụng dùng đúng bộ điều kiện bạn đã nhập, nên bạn không cần bấm `Tìm`
> trước.

> [!meo]
> Vẫn tìm được khi cột Sample Order No., Style, Created By hoặc Buyer đã được
> kéo sang vị trí khác trong layout riêng của tài khoản.

## Gặp lỗi thì sao

| Hiện tượng | Cách xử lý |
|---|---|
| Không hỗ trợ xem file | Mở Sample trên WFX và kiểm tra Style đã có file đính kèm hay chưa. |
| Không mở được Sample đã chọn | Tìm lại, chọn đúng dòng và bấm `Xem file đính kèm` lần nữa. |
| Không có kết quả | Kiểm tra Sample Order No., Style, Created By hoặc Buyer đã nhập. |
| Báo chưa đổi được Division | Tài khoản có thể chưa có quyền ở Division đó; đổi Division trên WFX hoặc nhờ quản trị cấp quyền. |
| Báo `Chưa đọc được` một mục | Mục đó chưa mở được nên danh sách file có thể thiếu; bấm `Xem file đính kèm` lại. |
